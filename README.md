# Fitness Goal Tracker App

This web application was created to fulfill Web Technology module’s requirements and does not represent an actual company or service.

## About the App
The Fitness Goal Tracker App allows users to create, read, update, and delete their fitness goals. Goals may include weight loss, running distance, and other fitness related objectives. The app is built using Node.js and Express.js and uses the Pug template engine for rendering views.
